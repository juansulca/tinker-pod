# Tinker pod examples

## Introduction

This repository contains examples of using the Tinker pod in various scenarios.
Each example is designed to demonstrate a specific feature or functionality of the Tinker pod.
All these examples are related to the implementation of the Tinker pod firmware. By following these examples,
you can learn the basics of the Tinker pod to create interactive and dynamic applications.

## Structure

- **examples/**: This directory contains various examples demonstrating the usage of the Tinker pod.
  Each directory contains a README.md file that explains the purpose of the example and provides instructions on how to run it,
  the dependencies required to run the example, and the schematic.

- Start with the [screen](screen/) example, that goes over a simple screen setup and displaying text.
- The [button](button/) example, a button for the tinker pod is set up and button event handling is demonstrated.
- The [draw](draw/) example, showcase how to setup a canvas and programatically draw on the screen.
- The [animation](animation/) example, demonstrate how to move elements on the screen every frame.
